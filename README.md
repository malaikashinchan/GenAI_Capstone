## 🎯 What This Does

A fully autonomous, Medallion-architecture data pipeline that:

1. **Generates** realistic Brazilian e-commerce data with intentional quality issues.
2. **Secures & Profiles** raw data using an advanced 4-layer NLP Cascade (Regex + SpaCy + Presidio + LLM).
3. **Inspects & Validates** data autonomously using dynamic Great Expectations rules generated by Llama 3.
4. **Heals** data quality issues automatically via a surgical LangGraph loop and LLM-generated SQL fixes.
5. **Transforms** clean data to the Silver layer while permanently hashing PII columns (SHA-256).
6. **Computes** business KPIs and generates executive LLM insights (Gold layer).
7. **Audits** everything, tracking exact lineage to Snowflake and telemetry to an MLflow tracking server.

**Zero human intervention.** The pipeline thinks, adapts, and heals itself.

---

## 🏗️ Architecture

```text
Generate → Bronze (Quality) → Silver (Clean) → Gold (Business) → Snowflake → Dashboard

  🟤 BRONZE : Profile → PII Detect (Presidio) → Schema Drift (Sentence-Transformers) → Rule Gen (LLM) → Validate
       ↓ Validation Failed → 🔧 Heal Agent (LLM generates SQL fix) → retry (max 3)
  ⚪ SILVER : Transform → PII Masker (SHA-256)
  🟡 GOLD   : KPI Engine + LLM Business Insights
  📋 AUDIT  : Lineage Tracker → Audit Writer → MLflow Telemetry
```

## ⚡ Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt
python -m spacy download en_core_web_sm

# 2. Configure .env with your Groq API key + Snowflake credentials
cp .env.example .env

# 3. Run continuously (generates + processes batches every 45s)
python3 run_continuous.py --loop --rows 200 --interval 45

# 4. Start the interactive multi-page Operations Command Center
streamlit run Home_Page.py

# 5. Evaluate Agents & Start MLOps Tracking Server
python3 mlflow_eval.py
mlflow ui
```

## 📊 Operations Command Center (Streamlit)

Live dashboard at `http://localhost:8501`:
- **Home**: Live telemetry, batch status, self-heals, and raw-to-clean yield.
- **Quality KPIs**: Mean-Time-To-Recovery (MTTR), Validation scores, and data distributions.
- **Governance & PII**: Visual donut charts of data classification and masking actions.
- **Schema Evolution**: Tracking semantic column drift (HIGH/MEDIUM severity) across batches.
- **Lineage Tracker**: Full end-to-end transparent audit of where data originated and where it was saved.
- **Data Explorer**: Directly browse `SILVER_CLEAN` and `SILVER_MASKED` tables stored in Snowflake.

## 🧪 Evaluation & MLOps Framework

We built a comprehensive ground-truth test suite and MLflow tracking server to empirically prove the agent's effectiveness:
* **`mlflow_eval.py`**: Compares the Agent's output against a Ground-Truth JSON using `scikit-learn` to calculate exact F1-Scores and Accuracies. 
* **Historical Telemetry**: Parses historical pipeline runs to calculate Self-Healing Success Rate, Recovery Success Rate, and MTTR.
* All results are securely logged into **MLflow** for persistent stakeholder observability.

## 🔧 Tech Stack

### Core & Orchestration
* **LangGraph & LangChain**: Directed acyclic graph (DAG) routing and agent orchestration.
* **Groq (Llama 3.3 70B)**: Lightning-fast LLM inference for Rule Generation and Self-Healing SQL.
* **Snowflake**: Enterprise Data Warehouse dual-storage layer.
* **Streamlit & Plotly**: Multi-page dynamic dashboards.

### Pre-Trained Local NLP & ML Models
* **Microsoft Presidio & SpaCy (`en_core_web_sm`)**: State-of-the-art Named Entity Recognition (NER) for the PII detection cascade.
* **Sentence-Transformers**: Local semantic embeddings used to detect intelligent Schema Drift.

### MLOps & Evaluation
* **MLflow**: Persistent tracking server and visual dashboard for pipeline evaluation.
* **Scikit-Learn (`sklearn`)**: Mathematical computation of F1 and Accuracy scores.

### Validation & Processing
* **Great Expectations**: In-memory ephemeral data context validation.
* **Pandas**: Core data manipulation and masking execution.
* **Python Regex**: Deterministic layer 1 detection.
* **Loguru**: Beautiful, colorful, structured terminal logs.
